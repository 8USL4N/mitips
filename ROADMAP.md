# ROADMAP (MVP)

## Что уже реализовано

- Полный CRUD для характеристик и лечений.
- Визуальный редактор критериев диагноза без JSON-поля.
- Разделение режимов create/edit во вкладках редактора.
- Удалена вкладка «Проверка эталона» из UI редактора.
- Решатель с rule-based фильтрацией и нейросетевым выбором при нескольких кандидатах.
- Статусы решателя: `determined`, `likely`, `neural_selected`, `not_determined`.

## Текущий backend-контракт

- `POST /api/solver/determine` — основной сценарий.
- `POST /api/solver/solve` — deprecated, оставлен для совместимости.

## Нейросетевой ранкер

- Самописная полносвязная сеть `N -> 16 -> M`.
- Обучение на синтетических случаях из базы знаний.
- Кэш/инвалидация модели по каноническому `knowledge_hash`.
- Сохранение весов в `backend/data/model-data.json` (или `MODEL_DATA_PATH`).

## Ограничения

- Система учебная и не проходит клиническую валидацию.
- Качество выбора зависит от полноты и качества базы знаний.
