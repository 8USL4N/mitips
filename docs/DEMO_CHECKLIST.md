# DEMO CHECKLIST (3-5 минут)

## Перед стартом

1. Запустить проект:
```bash
docker compose up --build -d
```
2. Прогнать smoke-проверку:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\smoke.ps1
```
3. Убедиться, что результат PASS.

## Сценарий защиты

1. Открыть `http://localhost:3000`.
2. На странице `Редактор знаний` убедиться, что вкладки:
   - `Системы организма`
   - `Характеристики`
   - `Диагнозы`
   - `Лечения`
   (вкладки `Проверка эталона` нет).
3. Во вкладке `Характеристики` создать новую характеристику.
4. Во вкладке `Лечения` создать новое лечение.
5. Во вкладке `Диагнозы` создать диагноз через визуальный редактор критериев (без JSON).
6. Перейти в `Решатель`, убедиться, что новая характеристика появилась в форме.
7. Ввести значения и получить результат.
8. Для случая с несколькими кандидатами показать:
   - статус `ml_selected`;
   - метод выбора `ML-модель`;
   - `confidence`;
   - список альтернатив и ранжированных кандидатов.

## Что проговорить во время демо

1. Логика решателя:
   - сначала rule-based фильтр;
   - при нескольких кандидатах — ML-ranker.
2. Редактор знаний теперь полностью CRUD и с явными режимами add/edit.
3. Все результаты объяснимы через таблицу критериев и совпадений.
4. Дисклеймер: система учебная, не для клинической диагностики.

## Критерии "готово к защите"

- Frontend доступен на `http://localhost:3000`.
- Backend docs доступны на `http://localhost:8000/docs`.
- `scripts/smoke.ps1` завершился с `SMOKE RESULT: PASS`.
- Backend-тесты проходят (`docker compose exec -T backend pytest -q`).
