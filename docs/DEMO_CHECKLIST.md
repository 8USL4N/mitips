# DEMO CHECKLIST (3–5 минут)

## Перед стартом

1. Запустить проект:
```bash
docker compose up --build -d
```
2. Прогнать smoke-проверку:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\smoke.ps1
```
3. Убедиться, что PASS.

## Сценарий защиты

1. Открыть `http://localhost:3000`.
2. На вкладке `Решатель` выбрать диагноз `Холера`.
3. Ввести признаки:
- Температура: `36.5`
- Характер стула: `водянистый`
- Боль в животе: `нет`
4. Показать результат:
- диагноз,
- план лечения,
- таблицу объяснений (совпадения).
5. Перейти в `Редактор знаний` -> `Лечения`.
6. Выбрать `Лечение холеры`, добавить новый шаг, сохранить.
7. Вернуться в `Решатель`, повторить расчёт и показать, что новый шаг появился в ответе.
8. Удалить временный шаг, сохранить.

## Что проговорить во время демо

1. Архитектура: `JSON БЗ -> FastAPI -> React -> Docker`.
2. Почему решение объяснимое: есть таблица совпадений по признакам.
3. Почему решение управляемое: изменения в БЗ сразу влияют на результат.
4. Дисклеймер: система учебная, не для клинической диагностики.

## Критерии "готово к защите"

- Frontend доступен на `http://localhost:3000`.
- Backend docs доступны на `http://localhost:8000/docs`.
- `scripts/smoke.ps1` завершился с `SMOKE RESULT: PASS`.
- Тесты backend проходят (`docker compose exec -T backend pytest -q`).
