# DEMO CHECKLIST (3-5 минут)

## Перед стартом

1. Поднять проект:
```bash
docker compose up --build -d
```
2. Прогнать smoke:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\smoke.ps1
```
3. Убедиться, что backend и frontend доступны.

## Сценарий демонстрации

1. Открыть `http://localhost:3000`.
2. На странице «Редактор базы знаний» проверить вкладки:
   - Системы организма
   - Характеристики
   - Диагнозы
   - Лечения
3. Проверить, что вкладки «Проверка эталона» нет.
4. Создать новую характеристику.
5. Создать новое лечение.
6. Создать диагноз с новой характеристикой.
7. Перейти в решатель, ввести значения и получить результат.
8. Для кейса с несколькими кандидатами показать:
   - `status = neural_selected`
   - `selection_method = neural`
   - `confidence`
   - `alternatives` и `ranked_candidates`

## Что проговорить

1. Сначала работает rule-based фильтр.
2. Если остаётся несколько кандидатов, включается самописная нейросеть.
3. Веса и метаданные модели сохраняются в `backend/data/model-data.json`.
4. Система учебная и не предназначена для клинической диагностики.
